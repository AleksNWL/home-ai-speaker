# Корпус и экран

## Цели корпуса

- Поместить Rock Pi 4 Plus + USB mic (FiFine AM8) или встроенный mic
- Выход на активные колонки Crown (или встроенный динамик позже)
- Вентиляция SoC (прорези снизу/сзади, опционально 40 мм fan на 5V)
- Фронт под экран 3.5–7" (HDMI/DSI)

## Габариты ориентиры (мм)

| Деталь | Примерно |
|--------|----------|
| Rock Pi 4 | 85 × 56 × 20 (с радиатором выше) |
| Экран 5" | ~120 × 75 × 8 |
| Зазор вентиляции | ≥ 8 мм вокруг платы |
| Внутренний объём MVP | 160 × 110 × 70 |

STL-модели печатай после финального экрана и расположения портов USB/Ethernet/HDMI.

## Файл `enclosure_preview.scad`

Параметрический черновик корпуса (OpenSCAD). Открой в [OpenSCAD](https://openscad.org/), подгони `screen_w/h`, экспортируй STL.

## Экран (kiosk)

1. Оркестратор поднимает UI на `:8787` (`display/`)
2. На графической сессии Armbian:
   ```bash
   sudo cp systemd/home-ai-display-kiosk.service /etc/systemd/system/
   sudo systemctl enable --now home-ai-display-kiosk
   ```
3. Либо вручную: `chromium --kiosk http://127.0.0.1:8787/`

UI показывает статус: ожидание / слушаю / думаю / говорю, транскрипт, ответ, трек.
